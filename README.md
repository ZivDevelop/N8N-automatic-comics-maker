 n8n Automatic Manga Generator

An autonomous AI agent workflow built in n8n that converts narrative text into sequential manga pages.

##  Project Status

* **Text Generation:** **Functional.** The AI agent perfectly processes narrative inputs into structured, sequential comic panels.
* **Image Generation:** **Limited.** The image rendering pipeline is currently restricted to manage API rate limits and high credit consumption.
